# Code of Conduct

## Our standard

Everyone participating in the JARVIS project is expected to be respectful, constructive, and considerate. We welcome contributors with different experience levels and backgrounds.

Expected behavior:
- Be respectful when discussing ideas, reviews, and disagreements.
- Give actionable feedback and accept constructive criticism.
- Focus on the work rather than attacking people.
- Respect privacy. Do not publish another person's private information, credentials, or logs.
- Keep discussions relevant and welcoming to newcomers.

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, doxxing, and deliberately disruptive conduct.

## Maintainer responsibility

The project maintainer may edit, remove, or decline comments, issues, or contributions that violate this code and may restrict participation when necessary.

## Reporting

If you experience or witness unacceptable behavior in a project space, contact the repository maintainer privately through GitHub. Do not include sensitive personal information in a public issue.
